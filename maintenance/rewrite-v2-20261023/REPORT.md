2026-10-23。源码已完成四模块及原 UI 接口兼容的候选实现，未部署生产。真实小绿瓶样例已跑完允许的一次全文重写，结果仍需修订，不能宣称系统质量验收通过。

## 实现范围

- `geo_source_cards/rewrite_v2/structure_parser.py`：全文语义骨架、内容和协议缓存、显式人工确认，确认绑定所查看的哈希；可编辑骨架，保留历史。
- `material_manager.py`：完整原始知识库和分类原句同时保留，不依靠旧事实白名单删掉数据。
- `full_writer.py`：一次生成完整 Markdown，按确认骨架行文，科普／排行分流；只允许一次全文重写。后续提示明确原 Word 比旧摘要完整，要求相关数字落到正文，禁止虚构商业合作与无依据的竞品优劣。
- `quality_reviewer.py`：先风格后事实，风格失败跳过事实；退稿须有具体指令，可选建议单列，证书绑定实际正文、骨架、来源和产品。模型审核不等于法律或医学认证。
- `integration.py`：接入既有 research/writer/review 队列、版本目录、Word 导出、交付回执与下载验证。旧任务继续原流程，新任务设置独立版本字段。
- `creation/studio.py`：保存原 Word 提取全文；历史产品快照只恢复自身对应的原文件。
- `creation/runtime.py`：兼容旧文章列表和下载，增加骨架 inspect/approve 操作；操作幂等、暂停状态保持；费用使用原共享账本。
- 旧自动修补、手工补丁和 quality-repair 路径拒绝 V2，避免绕过一次全文重写上限。未知 API 请求仍不得自动重发。

UI HTML、布局和交互代码未为本次修改。骨架确认可使用现有受保护 action 接口，或 `python -m geo_source_cards.rewrite_v2 pending/approve` 命令；新范文在确认前不会进入 Writer。
