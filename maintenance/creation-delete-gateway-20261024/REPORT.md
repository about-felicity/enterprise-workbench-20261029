# 创作任务删除修复（2026-10-24）

已修复并发布到实际主界面。此前仅在 8804 独立页面验收删除，遗漏了主界面的转发路径和长 iframe 场景。

## 原因

- 主界面网关未允许 `control/plan_delete`，请求返回 404「创作接口不存在」。
- 原生确认对话框在整个 iframe 中居中，长列表底部点击后对话框位于屏幕之外。实测 y=-828px，页面可视高度 950px。

## 修复

- 增加删除接口白名单，保留来源、CSRF、操作编号和公网前缀校验。
- 改为当前任务旁边的确认区；取消不发送请求。
- 提交中禁用按钮并展示进度，失败就地展示原因，支持重试。自动轮询保持确认区。
- 等待宿主 iframe 实际调整高度后再次定位确认区，避免手机底部裁切。
- 成功后立即移除任务；已有素材、文章及费用记录按原软删除语义保留。

- 覆盖列表底部可见性、取消、错误提示、轮询、提交禁用、重复点击、幂等重放、刷新后不恢复、390px 窄屏显示。
- 线上浏览器错误为零；12 个原任务全部保留，眉毛 7 篇文章仍在，测试未触发付费采集或写作。
