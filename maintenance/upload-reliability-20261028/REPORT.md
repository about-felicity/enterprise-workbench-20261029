# 产品图片上传与知识库整理（2026-10-28）

已部署至本地服务器 192.168.31.106 的内容创作模块，并同步修复 1any.top 公网入口。此次按用户明确的修复请求实施，包含服务端和公网代理变更。

## 已确认原因及修复

- 图片上传原先与耗时创作操作共用全局锁；现在使用独立操作锁和产品图片写入锁，不再等待创作任务。
- 每张上传完成后原先都刷新完整工作台状态；现在走独立上传状态接口，成功后直接更新图片列表。
- 公网上传入口原先只允许 2 MB 请求，与页面 5 MB 文件限制不一致；图片经 Base64 编码后还会增大。上传入口与认证子请求均调整为 8 MB，保留登录校验。
- 公网链路实测明显慢于内网：约 3 MB 文件内网保存 0.091 秒，公网完整请求 211.932 秒。延长前端上传等待、开启公网 JSON 压缩；网络传输速度本身仍是限制。

## 用户可见功能

每张待传图片独立预览，显示文件名、关联产品、大小、进度、保存结果和失败原因；每批最多 3 个并发上传。失败图片可单独重试，其他图片继续。浏览器保存待传队列，刷新后可以恢复。重试沿用操作编号，内容哈希避免重复保存。产品已保存图片全部以缩略图展示，可打开原图。支持多选、文件夹及拖放。

## 知识库

30 个入口合并为 20 个：19 个已建产品各一个入口，另有一个独立的新产品待分析。10 个旧重复入口转为重定向，最新资料作为当前上传版本，历史资料留作追溯。新上传会按同名、别名及文件校验去重；同一文件重复上传不再创建重复版本。

25 张图片从旧重复记录归回产品，原有 28 张原图全部保留并通过哈希校验。未擅自发布尚待分析的资料，既有产品事实和创作任务 JSON 保持不变。
