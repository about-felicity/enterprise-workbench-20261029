# 企业工作台模块清单

核对日期：2026-10-26。项目显示名称统一为「企业工作台」，包含网页侧栏品牌与浏览器标签页标题。

## 核心模块归属

| 模块 | 本地代码位置 | 生产运行位置 / 服务 | 工作台入口 |
| --- | --- | --- | --- |
| 统一网页工作台 | `geo-monitor-deploy/dashboard-integration/app` | `/opt/monitor/yuanbao_monitor/dashboard`；`monitor-dashboard` | 首页、企业概率监控 |
| 无头 Android 模拟器与原生采集 | `redroid-deploy`、`yuanbao-deploy`、`redroid` | `/home/user/redroid-doubao`、`/home/user/redroid-yuanbao`；豆包、元宝 Android 容器 | 采集控制；模拟器本身在后台运行 |
| GEO 采集调度与状态 | `geo-monitor-deploy`、`geo-source-card-collectors` | `/opt/monitor/geo-capture`；`geo-monitor-status` 与各批次服务 | 采集控制 |
| GEO 入库与分析 | `geo-monitor-deploy/server-source`、`source-snapshot/server/opt/monitor` | `/opt/monitor`；`monitor-dashboard-api`、接收器、product/content worker | 模型总览、问题对比、信源洞察、品牌与产品、回答审计 |
| 内容创作、产品知识库及图片、成稿下载 | `geo-monitor-deploy/creation`、`geo-monitor-deploy/creation-go`、`geo-source-card-collectors/geo_source_cards` | `/opt/monitor/geo-content`；API、Go runner、studio、materials 服务 | 内容创作中心内各标签页 |
| DeepSeek 浏览器插件与回传 | `deepseek-browser-deploy/public_client`、`deepseek-browser-deploy/public_ingest` | 独立采集/回传服务 | 同事端插件采集后回传到 GEO |

**无头模拟器、GEO 抓取分析、内容创作都属于这一套项目。** 它们是多个协作的进程和容器，不是全部装进一个前端容器。内容创作的 Go 调度与 Python 适配/引擎并存。

DeepSeek 仍按既有配置使用，运行中的历史模拟器容器不代表已启用自动采集。本次更名没有调整任何采集通道。

## 同目录内的其他内容

- `multi-agent-content-studio`、`writing-agent`：另有独立工具代码，不能等同于当前工作台上线的创作引擎。
- `ecommerce-review-exporter`：独立电商评价导出插件，未作为当前工作台菜单模块接入。
- `source-snapshot`：源码恢复副本；`maintenance`：维护和验证记录；`outputs`、`deliverables`、`交付文件`：成果及交付资料。
