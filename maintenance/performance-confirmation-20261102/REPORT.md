# 员工绩效确认

用户确认：共用现有geo_admin账号，每名员工在本人卡片自行设置个人绩效确认密码，不新增网站账号、邀请码或员工绑定。确认窗口每月最后一天北京时间00:00（包含）至18:00（不包含）。

实现：
- 员工卡片显示未确认、已确认、已逾期；点击卡片可设密、改密和月底确认。
- geo_admin只能用个人密码完成对应员工的确认；superadmin可重置密码，不能代员工确认。首次设密由员工自行选择本人卡片，符合共用登录账号的产品要求。
- 密码PBKDF2 SHA256、600000次、随机盐；连续5次错误锁定15分钟，失败次数持久化。已有密码不可首次设置覆盖，修改必须校验原密码。
- 确认使用服务端生成、绑定员工/月/会话/密码版本的5分钟预览，保存当时分数、系数、全部current明细及SHA256和时间。一个员工每月仅一条记录，重复提交返回原记录。输入数据以后变化不改写已确认快照。
- 后端按北京时间再次校验确认窗口；未来月、过期月、18点及之后拒绝。预览有参考值标识时展示数据不齐说明，允许员工明确确认当前参考值。
- 复用现有performance-entry公网签名身份网关与CSRF，不增加公网裸露接口，不修改账号密码或Nginx权限。仅该路径身份签名有效。
- 确认存储在已有performance.sqlite的新表，不改历史流量、费用或绩效算法。重置密码保留历史确认，审计设密、改密、重置与确认操作。

测试：11项本地及服务器隔离数据库测试通过，生产前端构建通过。测试覆盖窗口边界、闰年/时区、密码不可覆盖、校验失败持久化锁定、角色权限、幂等、快照保留、会话绑定及重置保留历史。未在生产设置任何员工密码或伪造确认记录。
