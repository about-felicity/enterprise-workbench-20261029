# 文心旧验证阻塞自动复查与续跑（2026-10-27）

原逻辑遇到连续4次验证后把search_recovery_control.blocked持久置1；wait在打开浏览器前即退出，创作采集父进程另有blocked-wenxin_card.json。两层均无恢复探测，后续日期还继承旧标记，造成页面已恢复但任务永久停滞。

新增wenxin_retry服务与timer，每分钟检查是否有到期复查，实际网页访问受独立持久退避约束：立即检查一次，失败后15分钟、再失败后30分钟复查；连续3次不成功停止并记录needs_attention。浏览器锁忙不扣次数，主GEO最多等锁90秒；不会抢占其他采集。每次浏览器探测硬超时100秒，终止整个探测进程组。任务暂停或关闭时不复查/不恢复。

探测只用现有持久会话访问普通文心搜索；正常返回完整正文与信源才解除验证闸门。真实验证码不求解、不绕过；不换账号、不复制会话、不重建问题队列。探测失败不会清除旧闸门。成功后仅更新恢复控制状态并移除同一计划/会话的过期block标记，保留captures、任务ID和历史结果。主GEO启动原geo-web服务，内容创作由既有调度器续跑。导航异常后重新检查最终URL/页面，捕获真实验证码状态。

现场结果：洗发水现有会话探测获得486字正文和38个信源；防脱精华和主GEO会话随后也探测成功。三处旧闸门已解除。防脱精华2026-10-27文心6/6完成；洗发水文心从0推进到3/10；主GEO原157/168批次恢复运行，遵守共享60秒访问间隔。后续实际计数见verification/verification.json，不将启动服务等同于整批完成。
