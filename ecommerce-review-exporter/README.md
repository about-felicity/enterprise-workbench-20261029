# 淘宝京东评论导出助手

Chrome / Edge Manifest V3 扩展。支持淘宝、天猫和京东商品详情页：

- 自动尝试点击“查看全部评价 / 全部评价”入口；
- 自动展开“全文 / 展开 / 查看全文”评论；
- 自动滚动或点击下一页、加载更多；
- 用户可设置最大抓取条数；
- 去重采集用户名、评论、追评、日期、规格、评分、点赞数、图片和视频链接；
- 每轮自动保存到扩展本地草稿；页面跳转、刷新或京东安全验证后可恢复同一商品已采集的评论；
- 导出为真正的 Excel `.xlsx` 工作簿（不依赖第三方 CDN）。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`，或 Edge 的 `edge://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择整个 `ecommerce-review-exporter` 文件夹。
5. 安装后刷新已经打开的淘宝或京东商品页面。

## 使用

1. 登录淘宝或京东并打开商品详情页。
2. 点击浏览器工具栏中的“淘宝京东评论导出助手”。
3. 点击“打开页面抓取面板”。
4. 输入最大条数，点击“开始抓取”。
5. 完成后点击“导出 Excel”。

插件会保留草稿，导出后也不会自动删除。再次点击“开始抓取”会接着已保存的评论去重采集；要从零开始，请先点击“清空已保存的评论”并确认。京东跳转到安全验证页时，先看右侧面板是否显示“已恢复 N 条”，如已恢复可直接导出。不要在未导出时清空草稿。

注意：1.0.3 及更早版本只把评论存在页面内存中，跳转后显示 0 时无法通过新版自动找回。可以先尝试浏览器“后退”；若原商品页的计数恢复，立即导出，再更新插件。若计数仍为 0，旧版没有可恢复的本地草稿。

网站会不定期调整页面结构。如果自动入口没有打开，可先手动点击页面里的“查看全部评价/全部评价”，再点击开始抓取。插件只读取当前账号在页面中正常可见、已经加载出来的评论，不绕过登录、验证码或访问限制。

天猫或京东商品页可能只显示几条评价预览。插件检测到完整评价弹层未打开时会明确提示，不会把预览评价当成完成全部抓取。京东新版评价弹层使用虚拟列表，插件会逐屏滚动并采集，避免直接跳到底部漏掉中间评论。

如果你已经安装过旧版本：打开 `chrome://extensions/`，找到“淘宝京东评论导出助手”并点击卡片上的刷新按钮，然后刷新商品详情页。更新后评价弹层会逐屏向下滚动加载更多，只有滚动和评论数量都不再增加时才结束。
