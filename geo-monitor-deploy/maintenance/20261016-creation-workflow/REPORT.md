# 产品知识库和每日创作任务工作流（2026-10-16）

正式 `http://192.168.31.106:3000/#creation` 已改为用户要求的主流程：导入产品Word→确认保存知识库→配置产品的问题/模型/轮数/日期/采集及分析仿写时间→每日自动采集、分析、创作、独立审稿→Word成稿。原手动复用素材和单项队列收进高级操作，原94篇成稿保留，产品/日期筛选与打包继续可用。

## 知识库

支持5MB以内.docx的正文和表格文字，显示提取预览，用户确认名称/品牌/受众/事实后保存。原Word和SHA256、文件名、提取记录私密保存在studio/imports；产品以版本保存在studio/products和versions。拒绝无文字、错误ZIP/XML、超限/外部实体文档。扫描图片不伪称已识别。Word文字作为用户产品资料，未声称独立认证；保留旧事实证据和原引擎的产品事实、证据、审稿和Word门槛。

## 每日编排

新增 `creation/studio.py` 与 `geo-creation-studio.service`，配置在studio/plans，每日账本studio/days/日期/plan.json。一个产品可有独立每日任务：问题、模型、每题采集轮数、每个问题每类篇数、首次日期、北京时间采集开始及分析最早时间、启用开关。任务到点自动跑；素材全齐且达到分析时间后，以“每日任务+问题”固定幂等号建立原引擎持久队列，每题独立研究写作审稿。费用仍共享原单篇0.35/每日10元账本，未放宽预算或质量检查。

原产品及16题01:00专用采集已迁移显示且原采集仍启用。**迁移配置的自动付费写作尚未启用**；04:00是可编辑的分析时间初值，没有在未获具体设置时按它创建付费队列。用户导入/确认产品、设置所需时间并点击“保存并启用每日任务”后才接通自动创作。无需另问审批，按钮就是用户配置操作。首次原采集仍为10/17 01:00；不把尚未到点的计划称整夜实采通过。

多产品采集存不同私有目录，通过同一账号锁和全局发送时钟排队，主GEO优先，DeepSeek600秒，百度后文心，锁忙非阻塞退避。均直接collector、不进GEO bridge/receiver/PG。跨天未完成任务继续原日期；当日采集开始后冻结产品知识、问题及写作配置，修改应用之后批次，避免换产品或混题。旧任务暂停只约束相应日期，当前问题/API安全收尾；当日新队列检查暂停，入队结果合并不覆盖并发暂停。未知API发送沿用原保护，不盲重发。
