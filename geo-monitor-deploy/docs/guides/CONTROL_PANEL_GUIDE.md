## 使用方式

1. 右侧“下次任务设置”每行一个问题，设置每题轮数与最小发送间隔，点击“保存设置”。这里修改的是下次任务，左侧当前任务的参数不会改变。
2. 当前任务结束，或暂停/停止已生效后，点击“开始新任务”。每次创建独立批次；重复点击或重复 HTTP 请求不会重复创建任务。旧队列、正文、信源和回执保留在历史中。
3. “暂停”不再开始下一题，等待当前题完成、完整结果与 GEO 回执都保存后才停。页面会显示“正在暂停”，随后为“已暂停”。
4. “继续任务”恢复同一批次，跳过已完成题目，不重置计数。发送结果未知的题目不能通过继续按钮重发。
5. “停止此任务”同样排空当前题，然后结束本任务，历史证据保留。停止的批次不使用继续按钮，后续使用“开始新任务”。
6. 豆包、元宝与 DeepSeek 提供“校验登录”，校验本身不发送问题；采集中需先暂停并等待排空。百度、文心不显示登录操作。
7. 豆包显示的是当前本机账号与登录页面观测，账号只显示脱敏尾号；不把本机登录状态当作服务端令牌永不过期的保证。DeepSeek 必须最近5分钟内校验为 ready，才允许开始或继续。
8. DeepSeek 原内容工作台登录过期时，先在原工作台完成登录，再点击“同步内容工作台登录”。该操作仅在原浏览器空闲且持有锁时读取会话，在内存中同步到独立 GEO 浏览器，再实时校验；不输出 cookie/token。

最小间隔：豆包／元宝30秒、DeepSeek300秒、百度/文心60秒。默认分别45/600/60秒，百度与文心仍共享串行通道与搜索时间状态。最大20轮，最多500个不同问题。百度相同正文与完整信源只回传一次，五轮观测保留，未取得完整卡片单独计数。
