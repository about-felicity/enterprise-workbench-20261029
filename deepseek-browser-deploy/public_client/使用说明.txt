# DeepSeek 多电脑采集与公网回传 0.4.0

多台同事电脑可同时运行，每台独立进度，也可随时手动开始。无需和服务器在同一局域网。将原始安装包分别发给获授权的同事；包内有仅用于登记设备的凭据，请勿公开发布。

## 首次使用（Windows / Chrome）

1. 将整个安装包解压到固定目录。无需自己安装 Python。
2. 双击“START.cmd”（中文启动文件也可用）。脚本自动检测 Python；没有可用环境时，从 python.org 下载官方安装包，验证数字签名后安装到当前用户目录，然后自动启动本地接收器。首次需联网，通常无需管理员权限。出现“准备完成”后按提示安装插件；脚本窗口可以关闭，接收器在后台继续运行。
3. Chrome 打开 chrome://extensions，开启开发者模式，点击“加载已解压的扩展程序”，选择本包的 extension 文件夹。
4. 自己打开 https://chat.deepseek.com 并登录，打开插件，检查问题和轮数后点击开始。默认21题、每题3轮，提问间隔随机10–15分钟，关闭深度思考、开启智能搜索。

默认关闭每日自动执行，可以随时手动开始。需要定时的电脑可勾选“每天北京时间09:00执行”。同一台电脑已有运行或暂停任务时，先继续或完成该任务；不同电脑互不占用队列。

## 结果与回传

保持电脑不休眠、Chrome和DeepSeek页面运行；关闭电脑后不会继续采集。
插件显示当前任务进度，本机结果和回传队列保存在data目录。
公网回传地址已预配置，无需填写服务器内网IP或网站密码。
断网时先保留本地结果，网络恢复后自动重试原回传；只有服务器确认processed才计入已回传，不会因为上传失败重新提问。
数据进入原有DeepSeek接收、分析流程，每条新记录带独立设备编号。不同电脑同题属于不同观测，不代表覆盖更广地区或真实用户推荐概率。
登录失效、账号限制或发送状态不明时停等核对，不自动绕过限制或重发未知问题。

## 更新与排错

每台电脑首次启动生成独立编号和上传密钥。分发原始ZIP；不要分享已使用目录中的config/deepseek_sync.json、config/device.json或data。检测到机器变化时会重新登记。
更新时保留config与data，替换源码后在扩展管理页重新加载。安装0.4.0时停用同一Chrome中的旧DeepSeek采集扩展，避免同时操作同一网页。
若下载或安装失败，检查网络，安装日志在 %LOCALAPPDATA%\DeepSeekCollector\installers\python-install.log；接收器日志在data/receiver_error.log。本地端口8767。端口被占用时不要停止不明进程，可运行restart_receiver.ps1重启本包接收器。
公网凭据仅能登记设备与上传DeepSeek结果，不能登录管理面板、控制其他模型或访问数据库；管理员可单独停用某台设备。

自动安装使用 Python 官方每用户安装参数，保持原系统 PATH 不变。参考：https://docs.python.org/3.13/using/windows.html#installing-without-ui

启动前请完整解压ZIP，进入 DeepSeekCollector 目录，再运行 START.cmd。START.cmd 与 start_monitor.ps1 必须在同一层，不要仅复制启动文件、不要在压缩包预览里运行。出现文件缺失提示时先检查解压目录；如安全软件提示移除了文件，查看具体提示，不要关闭安全防护。
