DeepSeek 本机浏览器采集与GEO回传

1 双击“一键启动DeepSeek监控.cmd”，启动本机接收与自动回传。
2 在你平时使用的Chrome打开 chrome://extensions/ ，开启开发者模式，点击“加载已解压的扩展程序”，选择本文件夹下的 extension 文件夹。
3 自己打开 https://chat.deepseek.com/ 并登录，刷新页面；打开插件，确认21个问题、每题3轮、随机10–15分钟，关闭深度思考、仅开启智能搜索，然后点击“开始”。

今天的接续
2026-10-19服务器已入库16条。首次开始会自动载入剩余47次，插件会显示47次；不重跑已完成的16条。日期过后恢复21题×3轮。请勿修改问题列表后再次开始，以免另外建立完整任务。暂停后使用“继续”，不要另建任务。

每天任务
首次由你手动打开浏览器并点击开始。插件默认开启每天北京时间09:00执行；之后电脑和Chrome保持运行时由插件定时启动，不由服务器代你打开浏览器。可在插件中取消每日执行。电脑与Chrome需要保持运行，睡眠、关机期间不能采集，联网恢复后自动重试回传。

结果与状态
采集结果和日志在data目录；回传排队期间保留本地outbox，只有服务器确认processed才记作回传完成。插件页面可查看正文、信源和日志，回传后进入原GEO监控分析。服务器的DeepSeek自动浏览器已停用，其他模型保持原来的每日任务。

保护配置
config/deepseek_sync.json包含本机回传凭据，不要分享、截图或上传仓库。无需将DeepSeek账号密码填入配置。本地接收器只监听127.0.0.1:8766。
